# Provenance

`M1_TRACEABILITY.md` and `M2_TRACEABILITY.md` are the original claim-to-source ledgers for the two precursor studies. They are preserved to trace numerical values and protocol decisions, not as independent statements of the unified manuscript's current claims.

Where an older M2 ledger describes a fixed template–MSA–sequence hierarchy, template-artifact-free distograms, or GA88/GB88 behavior before explicit coordinate sampling, the unified manuscript and its S1 Text take precedence. E427, E428, and E429 define the current robustness and coordinate-verification boundaries.
